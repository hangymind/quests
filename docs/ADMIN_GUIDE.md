# 管理员与使用指南

## 初始化

生产环境建议不执行演示 seed。完成数据库迁移后，第一个从注册页创建的账号自动成为超级管理员。确认账号可用后，可在反向代理层关闭 `/register`，或后续按组织需求增加邀请制注册。

## 创建和发布问卷

1. 在工作台选择“创建问卷”。
2. 从编辑器左侧选择题型，在中间预览，在右侧修改题目、选项和必填状态。
3. 选择“问卷设置”配置游客、登录、设备/IP 限制、提交次数和显示方式。
4. 保存并返回工作台，选择“发布”。公开地址为 `/q/问卷slug`。
5. 进行中的问卷可以暂停后继续；停止后不能恢复。

## 数据统计

工作台进入“统计”，可查看访问、完成、完成率、近七日趋势和逐题汇总。选择“导出 CSV”可下载逐份答卷，文件兼容 Excel 中文编码。

## 用户与权限

超级管理员可以查看用户和身份组、启用或停用账号。权限键包括问卷创建、编辑、发布、统计、导出、用户管理和身份组管理。不要停用唯一的超级管理员；系统也禁止当前管理员停用自己。

## 隐私提示

平台不保存原始 IP 或设备指纹，只保存不可逆哈希。问卷说明中仍应向填写者披露数据用途、保存时间与联系人，并按所在地法律处理个人信息。
